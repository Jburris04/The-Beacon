Publishing checklist

  1. Finish and save the draft.
  2. Generate the publish package.
  3. Unzip it, then copy its folders into the repository in GitHub Desktop.
  4. Choose Replace for matching files.
  5. Review Changes, commit with a clear summary, then click Push origin.
  6. Wait a minute and open the live Beacon site.
